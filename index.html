Projet de Fin d'Études (PFE)
01
AI & Fullstack Developer

MedAssist : Plateforme Médicale Intelligente

Fév 2026 – Juin 2026

Plateforme médicale intelligente et multiplateforme combinant une application mobile complète, une API backend haute performance et des modules d'intelligence artificielle avancés pour l'analyse d'ordonnances, la détection des interactions médicamenteuses et le suivi patient.

  • Application mobile & API : Développement cross-platform avec React Native (Expo) et un backend moderne Node.js / TypeScript.
  • Vision par ordinateur & LLM : Intégration de Gemini 2.5 Flash pour réaliser l'OCR d'ordonnances manuscrites avec extraction en JSON structuré (> 95% de précision).
  • Modèle Machine Learning : Entraînement d'un modèle TF-IDF & Random Forest classifiant la sévérité des interactions médicamenteuses (DDI) avec un F1-score de 91,0%.
  • Clustering Sémantique : Pipeline avec Sentence Transformers (all-MiniLM-L6-v2) et similarité cosinus (seuil ≥ 0.90) pour normaliser les nomenclatures de médicaments.
  • Analyse de Réseau : Modélisation des interactions médicamenteuses avec NetworkX (centralités de degré, d'intermédiarité et de proximité) pour cibler les interactions à risque critique.
  • Optimisation Base de données : Modélisation et gestion sous MongoDB Atlas couplé à Prisma ORM (requêtes ATC en 0.0085ms).
React Native (Expo) Node.js TypeScript Gemini 2.5 Flash (LLM) Random Forest TF-IDF Sentence Transformers NetworkX Prisma ORM MongoDB Atlas NativeWind
